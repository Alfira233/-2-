# Аттестационное задание №2: Анализ данных RFSD

## Описание проекта

Данный репозиторий содержит выполнение промежуточной аттестации №2 по анализу данных RFSD (Russian Financial Statements Dataset).  
В ходе работы были проанализированы финансовые показатели российских компаний за 2023 год с использованием библиотек Pandas, Matplotlib и Seaborn.

**Ссылка на исходные данные:** [https://github.com/irlcode/RFSD](https://github.com/irlcode/RFSD)

## Что было сделано

1. **Загрузка и подготовка данных**  
   - Использован streaming-подход для загрузки только 1000 строк и 20 наиболее информативных колонок (идентификаторы, показатели баланса, отчёта о прибылях и убытках, отчёта о движении денежных средств).  
   - Проведена очистка: обработка пропусков, замена бесконечностей, приведение типов.

2. **Описательная статистика**  
   - Выведены основные метрики (среднее, медиана, стандартное отклонение, асимметрия, эксцесс).  
   - Обнаружены аномалии: медианы ключевых показателей равны нулю, себестоимость продаж имеет отрицательные значения, прибыль от продаж имеет левостороннюю асимметрию.

3. **Гистограммы и выбросы**  
   - Построены гистограммы для выручки, чистой прибыли и валюты баланса.  
   - Выявлены выбросы с помощью метода IQR.  
   - Построены логарифмированные гистограммы для сглаживания асимметрии.

4. **Корреляционный анализ**  
   - Вычислена матрица корреляции Пирсона для всех 20 колонок (категориальные закодированы через factorize).  
   - Построена тепловая карта с аннотациями.  
   - Выявлены сильные корреляции (r > 0.98) между показателями масштаба: основные средства и внеоборотные активы, дебиторская задолженность и валюта баланса и др.  
   - Сделаны выводы о мультиколлинеарности и масштабном факторе.

5. **Диаграмма рассеивания**  
   - Построена диаграмма для пары с самой высокой корреляцией: line_1150 (основные средства) и line_1100 (внеоборотные активы).  
   - Добавлена линия линейной регрессии.  
   - Отмечено, что из-за нулевых медиан большая часть точек сосредоточена в начале координат.

6. **Выводы**  
   - Данные RFSD за 2023 год характеризуются сильной правосторонней асимметрией, высокой корреляцией между показателями масштаба и наличием значительного числа выбросов (крупных компаний).  
   - При построении аналитических моделей необходимо учитывать мультиколлинеарность и аномалии.

## Используемые технологии
